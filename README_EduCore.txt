==========================================
 EduCore - Smart Tool for a Smart School
       Quick Start Guide
==========================================

Thank you for using EduCore, your comprehensive School Management System.

--- Installation ---
1. Run the EduCore_Setup.exe file (or the main executable provided).
2. Follow the on-screen instructions to complete the installation (if applicable).
3. The application can be launched from the Start Menu or the Desktop shortcut.

--- First-Time Use ---
The first time you run the application, it will automatically guide you through the initialization process:

1. Admin Account Creation: 
   You will be prompted to create the first 'Admin' user account. This account has full permissions to manage users, settings, and finances.

2. School Setup: 
   Immediately after creating the admin, a "School Setup" dialog will appear. You must enter your basic school details (Name, Address, Phone, etc.). These details will appear on all generated reports, receipts, and certificates.

3. Login: 
   Once setup is complete, the login screen will appear. Log in using your new Admin credentials.

--- Getting Started ---
Once logged in, it is recommended to set up your master data in the following order:

1. Classes: Go to the 'Classes' tab and define your class levels (e.g., 1st, 2nd, 10th) and sections.
2. Staff: Go to the 'Staff' tab to add teachers and assign them to classes if necessary.
3. Students: Go to the 'Students' tab to enroll new students into the classes you created.

After this setup, you are ready to:
- Take Attendance.
- Record Fee Payments and generate receipts.
- Manage Payroll and Expenses.
- Generate Reports.
