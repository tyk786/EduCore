Product Release Notes & Build Verification

EduCore Release Changelog

EduCore is an offline desktop School ERP for 64-bit Windows 10 and 11 developed by SUBLIME ENTERPRISES. Storing all student, fee, payroll, and exam records inside a local encrypted SQLite database, EduCore ships regular reliability and security releases from a 30-day free trial or ₹4,499 perpetual license.

Version 8.2.3 — Enterprise Edition

Current Release (Oct–Nov 2026)
📥 Download v8.2.3 (.zip)

New Workflows & UI Upgrades

  • Dedicated Fees & Payroll Workspaces: Split unified finance into separate Fees and Payroll modules alongside Expenses, with distinct billing/salary dashboards and role-gated payroll sidebar visibility for authorized staff.
  • Weekly & Alternating-Week Timetables: Added day selection, subject distribution controls, and automated teacher collision prevention for both standard weekly and alternating-week school schedules.
  • Exam Matrix Save Guards & Preset Controls: Added unsaved-edit confirmation prompts when switching tabs, classes, or exam terms; single-cell mark clearing; and safer exam preset switching.
  • Native High-DPI Date Picker: Replaced legacy external calendar widgets with a built-in, click-anywhere-to-dismiss calendar picker.

Security Hardening, Licensing & Installer Safety

  • Login & Permission Hardening (Nov 2026): Added login rate-limiting/lockout protection, password-change ownership enforcement, strict permission checks on fee reversals and data exports, and percentage bounds (`0–100%`) on fee discounts.
  • Safe Documents & Exports: Enforced file-extension allowlists and 15 MB upload caps on student/staff attachments, safe text escaping in generated PDFs, and formula-injection sanitization in CSV exports.
  • Startup Backup Check & Single-Instance Installer Guard: Verifies database integrity on startup before login, enforces authorization on backup/restore actions, ensures atomic monthly fee/salary rollbacks, and detects running instances during Windows setup upgrades while preserving all local school data.
  • Licensing Enforcement & Documentation: Added strict activation enforcement on expired trials and published `v8.2.3` SHA-256 checksums, VirusTotal `0/72` Clean verification, and illustrated SmartScreen setup steps.

Version 7.2.3 — Reporting, Results & Packaging

September 19, 2026
  • Student Date of Birth (DOB) Support: Added student DOB capture, management, and printing across student profiles and academic records.
  • Redesigned Exam Results Workspace: Overhauled marks entry layout with clear total marks/percentage rows, streamlined exam selection, and cleaner report card generation.
  • Executive Multi-Page PDF Reports: Standardized school branding across Fee & Staff Ledgers, Expense Vouchers, Report Builder exports, Calendar PDFs, Exam Admit Cards (with school phone & email), and Student/Staff ID Cards; upgraded Student List by Class (30 students per page) and Attendance Summary PDFs (supporting all 5 statuses: Present, Absent, Half Day, Late, Leave).
  • Diagnostics & Packaging Synchronization: Enhanced missing-document and photo conflict diagnostics with direct entity details, and unified installer build pipelines.

Versions 5.2.3 & 5.2.4 — Security, Quota & UI Architecture

September 14–18, 2026
  • Active-Student Licensing & Unlimited Staff: License quotas strictly meter active enrolled students only—preserving Alumni, Transferred, Withdrawn, and Dropped records indefinitely without using paid student capacity, while imposing zero headcount limits on faculty and staff.
  • Dynamic Curriculum Subjects: Removed the legacy 10-subject limit per class so schools can configure 11+ curriculum subjects across grading and report cards.
  • Midnight Blue UI & Executive Dashboard: Refreshed the dashboard and sidebar into a Midnight Blue theme with live KPI cards, categorized actions, and dedicated Feedback and About views.
  • Role-Based Access & Transactional Audit Trails: Enforced granular permission checks across all administrative actions, ensured every mutation records an authenticated user entry inside the same transaction, and protected student/staff attendance and payment audit histories from accidental deletion.
  • Cent-Accurate Financial Reversals & Startup Auto-Backups: Eliminated rounding drift during multi-installment fee/salary reversals, added encrypted credential memory clearing and sanitized crash logs, and launched automated daily rolling 30-day backups with pre-archive integrity checks.

Version 2.3.8 — Offline Concurrency & Core Modules Overhaul

August 17–31, 2026
  • High-Concurrency Offline Database Engine: Enabled SQLite Write-Ahead Logging (WAL), automated lock retries, thread-isolated background task execution, and exact integer-cent financial precision.
  • Bulk Excel/CSV Import (Students & Faculty): Added template-driven Excel/CSV imports with column alias recognition, duplicate prevention, photo path support, and structured import result summaries.
  • Modernized Attendance, Library, Calendar & Classes: Introduced 5-status attendance marking with keyboard shortcuts, a 4-tab Digital Library circulation & stock catalog, multi-day holiday calendar scheduling, split-view Class management with Session Promotion, and one-click Student/Staff Profile PDF dossiers.

Versions 1.1.0 – 2.0.6 — Initial Windows Releases

July 2026

Initial public Windows distributions establishing EduCore's offline desktop architecture, local school database setup, and end-user license framework prior to the v2.3.8–v8.2.3 platform upgrades.
