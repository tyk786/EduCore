EduCore System Requirements & Windows Installation Guide

EduCore is engineered as a lightweight, native, pre-compiled Windows desktop platform. Review the hardware and operating system specifications below for optimal performance.

⚡ Zero External Runtime Dependencies

Unlike cumbersome web-based school portals that require installing complex Apache web servers, PHP runtimes, MySQL daemons, or Node.js environments, EduCore is distributed as a completely self-contained Windows desktop binary:

  • Embedded SQLite Engine: The high-speed database engine is compiled directly into the binary. No external database administration required.
  • ReportLab Vector Engine: Built-in vector graphics engine to produce crisp PDF marksheets, certificates, and ID cards without third-party printer drivers.
  • Offline Encryption: Cryptographic libraries are statically linked, ensuring hardware-speed encryption and validation without cloud calls.

💡 Windows Installation FAQs & Troubleshooting

Windows Defender SmartScreen Notice

Because EduCore is a direct desktop binary, Windows Defender SmartScreen may display a prompt upon initial launch. Simply click "More info" and then select "Run anyway" to proceed.

High-DPI Display Scaling on Laptops

EduCore is DPI-aware and adjusts automatically. If using a high-resolution 4K laptop monitor with custom scaling, 125% or 150% scaling provides the clearest balance of readability and layout clarity.

Visual C++ Redistributable

EduCore targets standard Microsoft Visual C++ runtime environments. Almost all modern Windows 10 and 11 installations already include this. If missing, the setup installer will prompt you to install it automatically.
